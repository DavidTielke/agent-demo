# Verifikationstools: frontend-developer-agent

Quellcode und Skripte der Tools, mit denen die Arbeit des `frontend-developer-agent` geprüft wird – z. B. Lint-Configs, eigene Lint-Regeln, Prüfskripte.

Die Regeln sind in `specs/frontend-developer-agent/verifikation.md` festgelegt. Was im Zielprojekt gebraucht wird, gehört als Ergebnis nach `harness/frontend-developer-agent/`.
